# 🔐 Secure Login Web App

A secure authentication system built with Flask.

## 🚀 Features
- User Registration & Login
- Password hashing using bcrypt
- Input validation
- Session management
- Two-Factor Authentication (2FA) using TOTP
- QR Code-based authentication

## 🛠️ Tech Stack
- Python (Flask)
- SQLite
- bcrypt
- pyotp
- qrcode

## ▶️ How to Run

```bash
pip install -r requirements.txt
python app.py

Open:
http://127.0.0.1:5000
